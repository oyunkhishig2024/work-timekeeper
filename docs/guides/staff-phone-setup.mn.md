# Timekeeper Work — утасны тохиргооны заавар (ажилтанд)

Апп таны ирц, гарсан цагийг **утас дэвсгэрт ажиллаж байхад** автоматаар бүртгэнэ. Утас апп-ыг «унтуулчихвал» бүртгэл алдагдана. Доорх тохиргоог **нэг удаа** хийнэ. Ойролцоогоор 5 минут.

> Утасны цэсийн нэр загвараас хамаарч бага зэрэг өөр байж болно. Олохгүй бол Тохиргооны хайлтад үгийг бичнэ.

## 1. Суулгах, нэвтрэх

1. HR-аас авсан QR кодыг утасны камераар уншиж, апп-ыг татаж суулгана. «Тодорхойгүй эх сурвалж / Install anyway» гэж асуувал зөвшөөрнө.
2. Нэвтрэх нэр, түр нууц үгээ оруулна. Эхний удаа **шинэ нууц үг** сонгоно. Нууц үгээ бусдад бүү өг.
3. Зөвшөөрлийн хуудсыг уншиж «Зөвшөөрч байна» гэж өгнө (хэвлэсэн хуудсанд гарын үсгээ зурсан байх ёстой).

## 2. Зөвшөөрлүүд (заавал)

Апп асуухад:

- **Байршил → «Үргэлж зөвшөөрөх» (Allow all the time)** ба **«Нарийвчлалтай» (Precise)** асаалттай.
  «Зөвхөн апп ашиглаж байхад» гэвэл дэвсгэрт ажиллахгүй.
- **Мэдэгдэл → Зөвшөөрөх.** «Ирцийн бүртгэл ажиллаж байна» гэсэн байнгын мэдэгдэл харагдана — энэ хэвийн, устгаж болохгүй.

## 3. Цэнэгийн хэмнэлт (заавал)

Тохиргоо → Апп → **Timekeeper** → Батерей (Battery / Battery saver) → **«Хязгаарлалтгүй» (No restrictions)**.

## 4. Xiaomi / Redmi / POCO (MIUI, HyperOS) — нэмэлт алхам

Эдгээр утас дэвсгэр аппыг хамгийн хүчтэй унтраадаг. **Бүгдийг** хийнэ:

1. **Autostart (автоматаар эхлүүлэх):** Тохиргоо → Апп → Зөвшөөрлүүд → **Autostart** → Timekeeper-ийг **асаана**.
   (Эсвэл «Security» апп → Permissions → Autostart.) Үүнгүйгээр апп дэвсгэрт ажиллаж чадахгүй, зарим утсанд цуцалж унадаг.
2. **Батерей:** Тохиргоо → Апп → Timekeeper → **Battery saver → «No restrictions»**.
3. **Сүүлийн апп-уудын дундаас түгжих:** «Сүүлийн апп» (дөрвөлжин товч / дэлгэцийн доороос дээш шудрах) → Timekeeper-ийн картыг удаан дарж → **Түгжээ (🔒) дарна**.
4. **Pop-up цонх** (шаардлагатай бол): Тохиргоо → Апп → Зөвшөөрлүүд → Бусад зөвшөөрөл → «Дэвсгэрээс цонх нээх» → зөвшөөрнө.

## 5. Өдөр тутам

- Апп-ыг сүүлийн апп-уудаас **шудраад хаахгүй**. Зүгээр орхино.
- Утсаа бүрэн унтраахгүй, «Хэмнэлтийн горим»-д оруулахгүй.
- Утасны **GPS / Байршил** асаалттай байх ёстой.
- Интернэтгүй газар (хонгил, зам) бүртгэл утсанд хадгалагдаж, холбогдмогц серверт очно.
- Апп-ын **«Утас»** хэсэгт шалгалт ногоон (✓) байвал бүх зүйл зөв. Улаан (✗) мөрийг дараад заасан алхмыг хий.

## 6. Асуудал гарвал

| Юу болов                                | Яах                                                            |
| --------------------------------------- | -------------------------------------------------------------- |
| Апп «Утас» хэсэгт улаан тэмдэг харуулав | Тэр мөрийн заасан тохиргоог асаана                             |
| Ирсэн цаг бүртгэгдээгүй                 | Апп-ыг нэг удаа нээ, «Утас» хэсгийг шалга; HR-д мэдэгд         |
| Утас солисон, апп-ыг дахин суулгасан    | HR-аас шинэ QR код авна                                        |
| Утас алдсан                             | Даруй HR-д хэл — хуучин утсыг хаана                            |
| Зөвшөөрлөө цуцлах                       | HR-д бичгээр хандана; ирцийг танд өөр аргаар (гараар) бүртгэнэ |

Асуулт: Хүний нөөцийн ажилтан.
